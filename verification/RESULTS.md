# 검증 기록

## 가을 낙엽 효과

- 기존 눈 구현을 분석하고 창문 clip, contain/DPR 변환, requestAnimationFrame, resize/visibility 처리 및 정리만 `windowParticles.ts`로 분리했습니다. 원본 좌표 유틸은 `windowGeometry.ts`에서 공유합니다. 라이브러리를 추가하지 않았습니다.
- 낙엽은 기본 12장, 단풍잎/길쭉한 잎, 황금빛·주황·적갈색·갈색에 음영/가는 잎맥/미세한 결을 적용했습니다. 16종의 모양·색·깊이 조합을 활성화 시 한 번 캐싱합니다. 매 프레임 그림 생성이나 React 상태 갱신은 하지 않습니다.
- 하나의 Canvas에서 가을은 낙엽, 눈 오는 겨울은 눈, 초가을/초겨울은 없음으로 선택합니다. 효과 변경 시 React effect cleanup으로 이전 프레임·리스너를 정리하고 Canvas를 지웁니다. 움직임 줄이기는 두 효과를 모두 중단합니다.
- `npm run build` 통과. `npm test` 20개 통과(기존 14개 + 낙엽 관련 6개). 가을 전용 선택, 기존 눈 테스트, 느린 회전/흔들림/대각선 이동, 캐싱, 모바일/데스크톱 contain 정렬, 3회 반복 계절 전환의 단일 프레임 루프와 리스너 정리를 검증했습니다. Canvas 검증은 모의 환경 및 좌표 계산이며 실제 픽셀 검증은 아닙니다.
- 변경 전후 비교로 배경/음료/음원 원본 파일, 배경 전환 모듈, 설정 UI, 오디오 및 김/불빛·로고 코드가 유지됨을 확인했습니다. 눈송이 스프라이트와 이동 계산도 그대로 유지했습니다.
- 실제 브라우저·기기 화면은 환경 제한으로 검증하지 못했습니다. 직접 확인 시 가을→눈 오는 겨울→초가을→초겨울을 반복 전환하고, 창틀/실내 물체의 경계와 낙엽의 색감·질감·밀도를 데스크톱 및 iPad에서 확인하세요.

## Canvas 겨울 눈 효과

- 기존 `object-fit: contain`과 원본 비율의 scene 영역을 확인했습니다. Canvas는 같은 scene 안에 위치하며, 실제 표시 크기의 contain 변환 및 DPR(최대 2)을 적용합니다.
- SVG 원형 눈 파티클을 제거하고 외부 라이브러리 없이 Canvas 2D / requestAnimationFrame으로 교체했습니다. 기본 22개, 아이보리 중심과 회청색 가장자리, 가까운 입자의 부드러운 불규칙 윤곽·옅은 결을 적용했습니다. 그라디언트/질감 스프라이트 5종과 창문 경로는 초기화 시 캐싱합니다.
- 기존 네 유리 영역의 교집합과 실내 물체 제외 마스크를 Canvas clip으로 적용했습니다. 창틀·벽·식물·조명·장식·컵 위치 제외 좌표를 자동 테스트로 확인했습니다. 이는 실제 픽셀 화면 검증과 구분됩니다.
- 눈 오는 겨울에서만 동작하며 다른 계절·움직임 줄이기에서는 프레임을 중단하고 Canvas를 숨깁니다. 숨겨진 탭은 일시 정지합니다. 중단/언마운트 시 프레임, ResizeObserver, resize/visibilitychange 리스너를 모두 정리합니다.
- `npm run build` 통과. `npm test` 총 14개 통과(기존 8개 + 눈 관련 6개). 눈 테스트는 크기·깊이·속도 다양성, 프레임률 독립 이동, 중단 후 이동 제한, 실제 마스크 좌표, contain 정렬, 모의 Canvas 환경의 캐시·정리를 검사합니다.
- 계절 전환 페이드, 음료 PNG, 김·불빛, 오디오·로고·설정 UI는 유지했습니다.
- 실제 브라우저 화면 검증은 하지 못했습니다. 현재 환경에서 서버/브라우저 실행이 제한된 점은 앞선 기록과 같습니다. 색감·질감·입자 밀도와 iPad 리사이즈 후 창틀 경계는 실제 화면에서 확인이 필요합니다.

## 계절·음료 선택 추가

- 기존 React + TypeScript + Vite 구성과 1672 × 941 contain 배치를 재사용했습니다. 적용할 AGENTS.md와 기존 테스트 스크립트는 없었습니다. 라이브러리는 추가하지 않았습니다.
- 실제 배경 4종과 투명 음료 PNG 3종을 확인했습니다. 기존 이미지가 `public/assets/backgrounds/winter-house.png`로 이동해 있었으므로 기존 import도 실제 경로로 수정했습니다.

- localStorage 기본값·유효성 검증과 저장 실패 처리, 선택/기본 에셋 실패 시 대체, 두 이미지 완료 전 대기 등의 자동 테스트 8개를 추가했고 모두 통과했습니다. `npm run build`도 통과했습니다.
- 기존 음원·재생 함수·loop 요소를 유지했고 김·불빛 효과도 유지했습니다. 추가 눈은 눈 오는 겨울에만 표시합니다.
- 브라우저 검증 미완료: 개발 서버 실행은 EPERM, Playwright Chrome 실행도 실패했습니다. 실제 컵 정렬·크로스페이드·모바일 터치·오디오 연속 재생은 검증하지 못했습니다.

## 컨트롤·로고 UI 개선 검증

- `npm run build`: TypeScript 검사 및 Vite 빌드 통과.
- 변경 전후 파일 해시와 소스 비교로 배경 이미지·음원·효과 설정, 배경 배치 CSS, 효과 SVG·CSS, 소리 재생 함수가 동일함을 확인했습니다. 라이브러리는 추가하지 않았습니다.
- 기본 상태는 48 × 48px 스피커 버튼만 표시합니다. 설정 패널은 숨김 상태로 DOM에 유지되어 접근성 연결(`aria-controls`)이 유효하고, 숨긴 조작은 Tab 순서에서 제외됩니다.
- 패널은 오른쪽 아래 버튼 위로 열립니다. 다시 누르기·바깥 pointerdown(마우스/터치)·Escape·Tab으로 설정 영역 벗어나기에 닫힙니다. 열 때 소리 버튼으로, Escape로 닫을 때 스피커 버튼으로 포커스를 이동합니다.
- 패널 폭은 기본 232px, 좁은 화면 216px이며 화면 폭과 safe-area에 맞춰 제한합니다. 높이도 화면과 safe-area에 맞춰 제한하고 필요한 경우 패널 내부에서만 스크롤합니다. 주요 조작 행은 44px 이상입니다.
- 실제 화면 검증 미완료: 개발 서버는 EPERM으로 실행되지 않았고 Playwright Chrome 실행도 실패했습니다. 패널 열기·닫기, 음량·소리·움직임 설정의 실제 브라우저 상호작용과 iPad 배치는 확인하지 못했습니다.
- 직접 확인 시: 기본 접힌 상태 → 버튼으로 열기 → 볼륨과 두 설정 조작 → 버튼/바깥 터치/Escape 각각 닫기 → 키보드 Tab 및 포커스 복귀를 확인하세요. iPad 가로·세로에서 그림 내부 로고와 화면 안쪽 패널을 확인하세요.

## 환경 제한

- npm registry 네트워크 접근 실패(ENOTFOUND). 다른 로컬 프로젝트에 이미 설치되어 있던 패키지를 이 프로젝트 안에 복사하여 빌드했습니다. 이웃 프로젝트 파일은 변경하지 않았습니다.
- 실제 사용한 패키지 버전과 lockfile을 저장했습니다. lockfile에 캐시된 원본 다운로드 URL·무결성 정보와 다른 플랫폼의 선택적 의존성을 포함했습니다.
- 개발 서버는 `0.0.0.0:5173`과 `127.0.0.1:5173` 모두 EPERM으로 시작하지 못했습니다.
- Playwright의 설치된 Chrome 실행은 SIGABRT/EPERM으로 실패했습니다. 화면 캡처, 실제 DOM/터치 및 오디오 상호작용은 검증하지 못했습니다.
- 음원 파일이 없으므로 실제 모닥불 재생은 검증하지 못했습니다.

## 김·불빛 가시성 조정

- 김의 최고 불투명도를 17%에서 45%로 높이고 선 두께를 7px에서 12px로 조정했습니다. 흐림은 3px에서 2.5px로 줄였습니다. 좌우 이동은 12px 이하, 상승은 68px로 유지하며 끝에서 사라집니다(원본 좌표 기준).
- 주변 불빛의 밝기 변화 폭을 키우고 벽난로 유리 안쪽에 따뜻한 빛의 작은 일렁임을 추가했습니다. 안쪽 효과는 별도 clipPath로 제한됩니다.
- 사용자가 변경한 눈 12초·불빛 3초 설정은 유지했습니다. 움직임 줄이기는 새 안쪽 불빛도 고정합니다.
- 실제 화면에서의 최종 가시성은 위 브라우저 실행 제한으로 확인하지 못했습니다.

## 실행 후 확인할 항목

음원 연결 후 추가 검증: 사용자 제공 `269062__nebulousflynn__wood-burning-stove.wav`로 재생 경로를 변경했습니다. WAV 헤더 확인 결과 48kHz, 16bit, 스테레오, 약 84.1초입니다. 빌드가 통과했으며 `dist/audio/`에 원본과 동일한 파일이 포함된 것을 SHA-256 비교로 확인했습니다. 실제 브라우저 재생은 환경 제한으로 확인하지 못했습니다. 아래 5번은 음원을 잠시 제거했을 때의 실패 처리 확인이며, 6번은 현재 연결된 WAV로 확인하면 됩니다.

1. `npm run dev`로 접속해 위 화면 크기에서 전체 그림과 컨트롤이 보이고 스크롤이 없는지 확인합니다.
2. 눈이 네 유리 영역 안에서만 움직이고 창틀·조명·식물·작은 집·가지 위를 덮지 않는지 확인합니다. 실내 물체 주변은 보수적으로 제외했습니다.
3. 찻잔 위 김과 벽난로 빛이 작은 범위에서 천천히 변하는지 확인합니다.
4. 움직임 줄이기를 켜면 추가 김·눈이 사라지고 빛이 고정되는지 확인합니다. OS의 움직임 줄이기도 같은 효과를 내는지 확인합니다.
5. 음원 없이 소리 켜기를 눌렀을 때 안내가 나오고 그림이 유지되는지 확인합니다.
6. 사용 권한이 있는 `public/audio/fireplace.mp3`를 넣고 버튼을 눌러 반복 재생·끄기·볼륨 조절을 확인합니다. 실제 iPad Safari에서도 확인합니다.
7. 키보드 Tab으로 버튼·볼륨·체크박스를 조작하고 포커스 표시를 확인합니다.
