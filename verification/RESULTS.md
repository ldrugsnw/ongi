# 검증 기록

2026-10-08. 교체된 색연필 이미지(`assets/winter-house.png`, 1672 × 941)를 기준으로 구현했습니다.

## 완료

- `npm run build`: TypeScript 검사 및 Vite 프로덕션 번들 생성 통과.
- 번들에 새 배경 이미지 포함, 한국어 문서 언어 및 외부 음원 미사용 확인.
- 이미지 비율 유지와 화면 내 전체 이미지 배치를 계산으로 확인:

| 화면 | 뷰포트 | 그림 영역 |
| --- | --- | --- |
| 데스크톱 | 1440 × 900 | 1440 × 810.4 |
| iPad 가로 | 1194 × 834 | 1194 × 672.0 |
| iPad 세로 | 834 × 1194 | 834 × 469.4 |

이는 CSS의 contain 배치 계산 검증이며 실제 브라우저 화면 검증 결과는 아닙니다.

## 환경 제한

- npm registry 네트워크 접근 실패(ENOTFOUND). 다른 로컬 프로젝트에 이미 설치되어 있던 패키지를 이 프로젝트 안에 복사하여 빌드했습니다. 이웃 프로젝트 파일은 변경하지 않았습니다.
- 실제 사용한 패키지 버전과 lockfile을 저장했습니다. lockfile에 캐시된 원본 다운로드 URL·무결성 정보와 다른 플랫폼의 선택적 의존성을 포함했습니다.
- 개발 서버는 `0.0.0.0:5173`과 `127.0.0.1:5173` 모두 EPERM으로 시작하지 못했습니다.
- Playwright의 설치된 Chrome 실행은 SIGABRT/EPERM으로 실패했습니다. 화면 캡처, 실제 DOM/터치 및 오디오 상호작용은 검증하지 못했습니다.
- 음원 파일이 없으므로 실제 모닥불 재생은 검증하지 못했습니다.

## 김·불빛 가시성 조정

- 김의 최고 불투명도를 17%에서 45%로 높이고 선 두께를 7px에서 12px로 조정했습니다. 흐림은 3px에서 2.5px로 줄였습니다. 좌우 이동은 12px 이하, 상승은 68px로 유지하며 끝에서 사라집니다(원본 좌표 기준).
- 주변 불빛의 밝기 변화 폭을 키우고 벽난로 유리 안쪽에 따뜻한 빛의 작은 일렁임을 추가했습니다. 안쪽 효과는 별도 clipPath로 제한됩니다.
- 사용자가 변경한 눈 12초·불빛 3초 설정은 유지했습니다. 움직임 줄이기는 새 안쪽 불빛도 고정합니다.
- 실제 화면에서의 최종 가시성은 위 브라우저 실행 제한으로 확인하지 못했습니다.

## 실행 후 확인할 항목

1. `npm run dev`로 접속해 위 화면 크기에서 전체 그림과 컨트롤이 보이고 스크롤이 없는지 확인합니다.
2. 눈이 네 유리 영역 안에서만 움직이고 창틀·조명·식물·작은 집·가지 위를 덮지 않는지 확인합니다. 실내 물체 주변은 보수적으로 제외했습니다.
3. 찻잔 위 김과 벽난로 빛이 작은 범위에서 천천히 변하는지 확인합니다.
4. 움직임 줄이기를 켜면 추가 김·눈이 사라지고 빛이 고정되는지 확인합니다. OS의 움직임 줄이기도 같은 효과를 내는지 확인합니다.
5. 음원 없이 소리 켜기를 눌렀을 때 안내가 나오고 그림이 유지되는지 확인합니다.
6. 사용 권한이 있는 `public/audio/fireplace.mp3`를 넣고 버튼을 눌러 반복 재생·끄기·볼륨 조절을 확인합니다. 실제 iPad Safari에서도 확인합니다.
7. 키보드 Tab으로 버튼·볼륨·체크박스를 조작하고 포커스 표시를 확인합니다.
